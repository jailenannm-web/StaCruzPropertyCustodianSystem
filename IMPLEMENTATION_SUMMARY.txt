SCHEMA CHANGES IMPLEMENTED
---------------------------

borrowed_items Table:
  ✓ Added: itemName VARCHAR(200)
    - Stores item name directly for faster queries
    - Eliminates need for JOIN in many cases
    - Auto-populated from properties/supplies tables
  
  ✓ Added: returnReason VARCHAR(200)
    - Replaces expectedReturnDate
    - Stores reason for return (more flexible than date)
    - Examples: "Project completed", "No longer needed"
  
  ✗ Removed: expectedReturnDate DATE
    - Old column that stored expected return date
    - Replaced by returnReason for better flexibility
  
  ✓ Added: Index idx_borrow_itemName
    - Improves search performance on item names

supplies Table:
  ✓ Added: assignedTo INT(11)
    - Tracks which user has the supply
    - Foreign key to users(userId)
    - Enables automatic borrowed_items creation
  
  ✓ Added: departmentId INT(11)
    - Tracks which department has the supply
    - Foreign key to departments(departmentId)
    - Mirrors properties table structure
  
  ✓ Added: Index idx_supply_assigned
    - Improves queries filtering by assignedTo
  
  ✓ Added: Index idx_supply_department
    - Improves queries filtering by departmentId
  
  ✓ Added: Foreign key fk_supplies_assignedTo
    - Links to users table
    - ON DELETE SET NULL (preserves data if user deleted)
    - ON UPDATE CASCADE (maintains referential integrity)
  
  ✓ Added: Foreign key fk_supplies_departmentId
    - Links to departments table
    - ON DELETE SET NULL
    - ON UPDATE CASCADE

ROLLBACK PLAN
-------------
If you need to rollback these changes:

1. Backup your database first:
   mysqldump -u root -p teamcruzim > teamcruzim_backup_before_rollback.sql

2. Execute rollback commands:
   USE teamcruzim;
   
   -- Remove new columns from borrowed_items
   ALTER TABLE borrowed_items DROP COLUMN itemName;
   ALTER TABLE borrowed_items DROP COLUMN returnReason;
   
   -- Add back expectedReturnDate
   ALTER TABLE borrowed_items ADD COLUMN expectedReturnDate DATE NULL AFTER borrowDate;
   
   -- Remove new columns from supplies
   ALTER TABLE supplies DROP FOREIGN KEY fk_supplies_assignedTo;
   ALTER TABLE supplies DROP FOREIGN KEY fk_supplies_departmentId;
   ALTER TABLE supplies DROP COLUMN assignedTo;
   ALTER TABLE supplies DROP COLUMN departmentId;
