   Solution: Create it first:
            1. Open MySQL Workbench
            2. Run: CREATE DATABASE teamcruzim;
            3. Then run CREATE_ACCOUNTS_NOW.sql again

❌ Problem: "Table 'departments' doesn't exist"
   Solution: You need to create tables first:
            1. Find: teamcruzim_database.sql
            2. Run that file first
            3. Then run CREATE_ACCOUNTS_NOW.sql

❌ Problem: Still getting "Invalid username or password"
   Solution: 
            1. Verify accounts were created:
               Open MySQL Workbench and run:
               SELECT * FROM users WHERE username = 'superadmin';
            2. Make sure you rebuilt the application
            3. Try exact passwords (case-sensitive!)
